How these comparisons work

Built from the same data/items.json leaderboards shown above (Artificial Analysis snapshots, top 10 per board). Names are normalized — e.g. Claude Opus 5.5 (max with fallback) → Claude Opus 5.5 — so variants collapse to one column. A model “wins” a board only when at least two compared models both report that board; otherwise no highlight. Missing = — (outside top 10, not tested).
